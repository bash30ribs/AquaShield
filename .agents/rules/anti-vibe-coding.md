# STRICT PERMANENT INSTRUCTION: ANTI-VIBE CODING & PRODUCTION STANDARDS

These rules apply FOREVER across all projects and codebases without requiring manual reminders:

## 1. Visual & Aesthetic Standards (No "Vibe Coding")
- **NEVER use purple gradients**, violet glow cliches, or generic AI neon templates. Use curated, intentional, domain-specific palettes (e.g. obsidian midnight navy + distress amber for marine/defense, crisp neutral slates).
- **NEVER use over-the-top scroll animations**, aggressive parallax warping, or gimmicky custom cursor animations. Keep motion purposeful, subtle, and responsive.
- **NEVER use wheel-shift buttons** or bizarre non-standard UI gimmicks.
- **NO emoji icons in hero titles or headings** (use clean, crisp SVGs or modern typography instead).
- **NO excessive em-dashes (`—`)** or AI-hallmarked linguistic patterns.

## 2. Integrity & Content Standards (No Fake Proof)
- **NEVER use fake reviews**, fabricated user quotes, fake testimonials, or fake customer counters.
- **NEVER use fake metrics** or arbitrary placeholder numbers masquerading as real statistics.
- **NEVER use AI stock slur photos** or generic AI hallucinated illustration tropes.
- **NEVER use AI slur copy**, boilerplate marketing buzzwords, or pretentious AI intros.
- **ALWAYS remove any "Made with AI" / "Powered by AI Assistant" badges** or tags.

## 3. Production Launch Requirements
Before considering any website or web app production-ready:
1. **Favicon**: Must include a high-contrast, sharp favicon (`<link rel="icon" ...>`).
2. **Legal Pages**: Must include a dedicated **Privacy Policy** page/modal and **Terms & Conditions** page/modal.
3. **Domain & SEO**: Proper title tags, meta tags, OpenGraph data, and clean canonical/custom domain configuration.
4. **Zero Mistakes**: Full end-to-end functionality, tested API endpoints, verified database migrations, and clean responsive layouts.
