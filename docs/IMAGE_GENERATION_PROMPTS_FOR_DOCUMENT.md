### 8. System Workflow Flowchart
*Where to place in document: Section 6 (Flowchart).*

```text
Generate an end-to-end user decision and system execution Flowchart for "AquaShield AI".

Flow Logic:
1. Start: User opens AquaShield Application.
2. Decision Diamond: "Is Internet Available?".
   - Branch NO (Offline Path):
     - Service Worker (sw.js) activates local asset cache.
     - User accesses cached disaster checklists and radar baseline.
     - If Emergency SOS is tapped: Application generates a pre-formatted SMS URI with GPS coordinates and opens native SMS composer directed to Coast Guard 1554 / Police 112 without data.
   - Branch YES (Online Path):
     - Fetch live ocean buoy telemetry (swell, wave height, wind).
     - User chooses an action:
       a) Check Beach Safety -> Displays Safe/Caution/Hazard badge.
       b) Evacuation Route -> Calculates safety-weighted path bypassing flood basins.
       c) Marine Life Rescue -> Submits stranded animal case to local NGO.
       d) Report Hazard Observation -> Uploads photo and GPS coordinates.
3. Forensic Gate for Hazard Photos:
   - Image enters Dual-Stream Neural Network (EfficientNet-B0 RGB + ELA stream).
   - Decision Diamond: "Is Image Authentic?".
     - NO: Flag as fake/tampered, suppress public alert, display warning.
     - YES: Mark verified, commit to database, display on live GIS radar, and alert first responders.
4. End State.

Format with standard ISO flowchart symbols (terminators, process boxes, decision diamonds, labeled branches).
```
